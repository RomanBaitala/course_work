# Курсова робота: Система управління готелем (Hotel Management System)

> **Дисципліна:** Документування програмного забезпечення та шаблони проектування  
> **Заклад:** Національний університет «Львівська політехніка»  
> **Варіант:** №3 — «Система управління готелем»

---

## 📌 Опис предметної області (Варіант 3)

Веб-додаток для автоматизації та управління роботою готелю.  
Система дозволяє клієнтам переглядати номери, здійснювати бронювання та підключати додаткові послуги, а адміністрації — відстежувати завантаженість номерного фонду, аналізувати виручку та керувати послугами.

### Основні функціональні модулі:
1. **Каталог номерів:**
   - Категорії номерів: *Економ*, *Стандарт*, *Люкс*.
   - Фільтрація: ціна, кількість спальних місць, зручності (Wi-Fi, кондиціонер, джакузі тощо).
   - Детальні описи та фотографії.
2. **Бронювання та розрахунок вартості:**
   - Онлайн-бронювання з вибором дат заїзду та виїзду.
   - Додаткові послуги: харчування, трансфер, SPA-комплекс.
   - Динамічний розрахунок вартості залежно від терміну перебування та програми лояльності.
3. **Персональний кабінет клієнта:**
   - Історія бронювань (активні, завершені, скасовані).
   - Можливість скасування та продовження терміну проживання.
   - Накопичення та списання бонусних балів.
4. **Адміністративна панель та звіти:**
   - Управління номерами, тарифами та послугами.
   - Звіт про завантаженість номерного фонду.
   - Фінансові показники (дохід за місяцями, прибутковість за категоріями).
   - Інформація про постійних клієнтів.

## 🏛️ Мапа GoF-шаблонів проєкту (Mapping to Domain Architecture)

Архітектура побудована за принципами **Domain-Driven Design (DDD)** та **Clean Architecture**: патерни органічно інтегровані у відповідні бізнес-модулі домену, а не винесені в штучні технічні папки. 

Нижче наведено навігацію за патернами для захисту курсової роботи:

| Шаблон GoF | Категорія | Розташування в коді | Призначення в системі готелю |
|---|---|---|---|
| **Factory Method** | *Creational* | `app/domain/factories/room_factory.py` | Створення категорій номерів (`EconomyRoom`, `StandardRoom`, `DeluxeRoom`) із відповідним набором зручностей та базовою ціною. |
| **Builder** | *Creational* | `app/domain/builders/booking_builder.py` | Покрокове конструювання складного бронювання з валідацією дат, гостя та послуг. |
| **Decorator** | *Structural* | `app/domain/pricing/service_decorator.py` | Динамічне додавання платних опцій (харчування, трансфер, SPA) до підсумкової вартості проживання. |
| **Strategy** | *Behavioral* | `app/domain/pricing/pricing_strategy.py` | Алгоритми розрахунку тарифів (базовий, сезонний, накопичувальна знижка клієнта). |
| **State** | *Behavioral* | `app/domain/booking/booking_state.py` | Керування життєвим циклом замовлення (`Created` ➔ `Confirmed` ➔ `CheckedIn` ➔ `CheckedOut` ➔ `Cancelled`). |
| **Observer** | *Behavioral* | `app/domain/events/` | Події та сповіщення гостя й персоналу про зміну статусу броні та нарахування бонусів. |
| **Facade** | *Structural* | `app/services/booking_facade.py` | Спрощений інтерфейс бронювання для клієнтського контролера (перевірка доступності + розрахунок + бронювання). |
| **Template Method** | *Behavioral* | `app/services/reports/report_generator.py` | Каркас генерації адміністративних звітів (завантаженість, виручка). |
| **Singleton** | *Creational* | `app/core/config.py` | Єдиний глобальний менеджер налаштувань системи та пулу підключень. |

## 📁 Структура проєкту

```text
course_work/
├── docs/                               # Матеріали курсової роботи та звіту
│   ├── diagrams/                       # Use Case та UML діаграми класів
│   ├── report/                         # Пояснювальна записка
│   └── specifications/                 # ТЗ та функціональні вимоги
│
├── backend/                            # Серверна частина (Clean Architecture + DDD)
│   ├── app/
│   │   ├── core/                       # Налаштування, Singleton, безпека
│   │   ├── domain/                     # Ядро доменної логіки (чисте ООП)
│   │   │   ├── models/                 # Сутності (Room, Booking, User, Service)
│   │   │   ├── factories/              # [GoF: Factory Method] Фабрики створення номерів
│   │   │   ├── builders/               # [GoF: Builder] Конструктор бронювання
│   │   │   ├── pricing/                # [GoF: Decorator, Strategy] Розрахунок цін та послуг
│   │   │   └── booking/                # [GoF: State] Життєвий цикл замовлення
│   │   ├── repositories/               # Рівень доступу до бази даних (Repository)
│   │   ├── services/                   # [GoF: Facade, Template Method] Прикладні сервіси
│   │   ├── api/                        # REST API контролери (FastAPI endpoints)
│   │   └── database/                   # Підключення до БД, міграції, демо-дані
│   └── tests/                          # Модульні та інтеграційні тести
│
├── frontend/                           # Веб-інтерфейс (клієнтська та адмін-частина)
└── README.md                           # Документація репозиторію
```
