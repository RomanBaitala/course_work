## 📌 Опис предметної області (Варіант 3)

Веб-додаток для автоматизації та управління роботою готелю.  
Система дозволяє клієнтам бронювати номери та додаткові послуги, а адміністрації — відстежувати завантаженість номерного фонду, аналізувати фінансові показники та вести облік клієнтів.

### Основні функціональні модулі:
1. **Каталог номерів:**
   - Перегляд доступних номерів за категоріями (*економ*, *стандарт*, *люкс*).
   - Фільтрація та пошук: за ціною, кількістю місць, зручностями (кондиціонер, Wi-Fi, вид на гори/місто тощо).
   - Фотографії, характеристики та детальний опис кожного номера.
2. **Бронювання та розрахунок вартості:**
   - Онлайн-бронювання з вибором дат заїзду та виїзду.
   - Вибір додаткових сервісів: харчування (сніданок/all inclusive), трансфер, SPA-послуги тощо.
   - Динамічний розрахунок вартості перебування з урахуванням обраних опцій, терміну та персональних знижок.
3. **Персональний кабінет клієнта:**
   - Перегляд поточної та минулої історії бронювань.
   - Можливість скасування або продовження бронювання.
   - Програма лояльності: накопичення та списання бонусних балів.
4. **Адміністративна панель та звіти:**
   - Управління номерами, тарифами та додатковими послугами.
   - Звіт про поточну та прогнозну завантаженість номерів.
   - Фінансові показники (дохід за місяцями, прибутковість за категоріями номерів).
   - Аналітика постійних клієнтів (рейтинг за кількістю візитів, сумою витрат).

## 🏛️ Застосування GoF шаблонів проєктування

| Категорія | Шаблон GoF | Призначення в системі управління готелем |
|---|---|---|
| **Породжувальні (Creational)** | **Factory Method / Abstract Factory** | Створення сутностей номерів різних категорій (`EconomyRoom`, `StandardRoom`, `DeluxeRoom`) та пакетів обслуговування. |
| | **Builder** | Покрокове конструювання комплексного замовлення на бронювання (`BookingBuilder`: номер + дати + набір послуг + знижки). |
| | **Singleton** | Єдина точка доступу до менеджера конфігурації, пулу з'єднань із базою даних та логера. |
| **Структурні (Structural)** | **Decorator** | Динамічне додавання платних опцій (харчування, трансфер, SPA) до базового тарифу номеру. |
| | **Facade** | Єдиний високорівневий інтерфейс (`HotelBookingFacade`) для спрощення процесу бронювання (перевірка доступності, фіксація броні, нарахування бонусів, розрахунок). |
| | **Adapter** | Адаптація зовнішніх сервісів (платіжні системи, SMS/email-сповіщення). |
| **Поведінкові (Behavioral)** | **Strategy** | Розрахунок вартості бронювання за різними тарифними планами (сезонний тариф, тариф вихідного дня, накопичувальна знижка клієнта). |
| | **State** | Управління життєвим циклом бронювання (`Created` ➔ `Confirmed` ➔ `CheckedIn` ➔ `CheckedOut` ➔ `Cancelled`). |
| | **Observer** | Повідомлення клієнта та адміністратора про зміну статусу бронювання або нарахування бонусних балів. |
| | **Template Method** | Алгоритм формування аналітичних звітів для адміністратора (кроки: збір даних ➔ агрегація показників ➔ форматування ➔ експорт). |
